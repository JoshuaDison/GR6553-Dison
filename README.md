# GR6553-Dison
This is my final project for Compuational Methods - GR6553. This repository contains: radar data, GFS data, code, output files, and GIF loops used for this project and produced by this project

Project Overview: This project examines the March 31st, 2023 Little Rock EF-3 Tornado. This project utilizes the SPC Day 1 Outlooks, the Little Rock Radar Site, Skew-T from the Radar Site, and the GFS to examine various meteorological elements prior to, and at the time of the event. 

RADAR Overview: The Radar data was gathered from the Little Rock, Arkansas. Both refelectivity, and velocity products were produced for the visualization of both the visable hook echo as well as the interior wind profile. The Radar loop that is produced is centered at the Little Rock Radar Site and goes from 2:01pm-2:53pm at approximatley 5 minute step intervals. The Data was gathered through the NEXRAD Level 2 THREDDS page. 

Gridded Model Data: The gridded model data was gathered from the Global Forecast System (GFS). Two different sets of gridded data were produced. First, an upper atmosphere set was analyzed. Starting from 00z March 31st, 2023 through 24z, 500mb Geopotential Heights, 500mb Absolute Vorticity, and 500mb-Winds were examined. These looked at the mid-to-upper atmosphere setup. It is evident through the loop that was produced the potent mid-level trough that came through the middle portions of the United States and into the Arkansas region. The data was gathered from the GFS THREDDS site. The next set of gridded model data looked at the lower atmosphere variables. Using the same time frame, 850mb Temperature in Celsius, 850mb Geopotential Height, and 850mb Winds were studied. These variables in conjuction with the upper atmosphere setup is crucial for understanding the kinematic setup of the outbreak day

Skew-T: Skew-T were analyzed as well. The data was pulled using the WyomingUpperAir request, using the date as "datetime(2023,3,31,0) and changing the last number based on the time desired. The name of the station is Little Rock, identified as "LZK". Pressure, Temperature, Dewpoint, wind direction, and wind speed were studied. Three different times for soundings were used, 00z, 12z, and 18z (approxamtely 1 hour before the tornado touched down)

Surface Analysis: The Day 1 SPC outlooks were used for the Surface Analysis. The code needed was used from the MetPY website. The files needed were .geojson files that were gathered from the Storm Prediction Center archives. Four different soundings were produced: 01z, 12z, 13z, and 1630z.
